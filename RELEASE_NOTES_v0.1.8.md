# StayActive v0.1.8

## Simple summary

You can now build rules visually with a point-and-click Rule Builder instead of editing JSON, and rules support more powerful conditions (AND/OR) and new actions (play sound, close instance, run script).

You can now persist identity pins across restarts and rename instances with custom labels, so your account mappings stay stable between sessions.

You can now set per-account performance profiles with individual duty-cycle overrides, and Smart Freeze automatically keeps the foreground Roblox window responsive while freezing background instances.

StayActive now detects Roblox error screens (277/268/279/264) and auto-terminates affected instances so they can be relaunched cleanly.

When a private server place ID and link code are configured, relaunched instances automatically rejoin the same private server using a deep link.

A new Analytics tab shows session uptime, biome changes, crashes, jump cycles, and a 24-hour event timeline with an uptime graph.

You can now show StayActive status on your Discord profile with optional Discord Rich Presence integration.

You can now update StayActive in one click from inside the app — it downloads the latest release, replaces the EXE, and restarts automatically.

A dedicated Relaunch webhook URL lets you route relaunch notifications separately from recovery alerts.
